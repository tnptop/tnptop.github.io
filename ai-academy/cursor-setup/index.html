Set up Cursor and run your first Agent prompt

Checked on: Cursor 3.24.9, macOS 15.8.1 (Apple Silicon), 2026-10-09.

Checked on: Cursor 3.24.9, Windows 11, 2026-10-09.

Time: about 20 minutes.

Do these steps before the session.

Press the right arrow key or click Next.

What you need

  • A Mac or a Windows laptop.
  • Your work Google account. This is the account of your work email. You sign up to Cursor with it in Step 2.
  • About 300 megabytes (MB) of free disk space for the download.
  • A stable internet connection and about 20 minutes.

Step 1: Download Cursor

  1. Open cursor.com/home in your browser. Type the full address, with /home.
  2. Click the download button for your system. The browser downloads one file.
  • macOS: the file name ends in .dmg. The file is about 300 MB.
  • Windows: the file name is CursorUserSetup-x64-3.24.9.exe. The file is about 205 MB.
Why /home

If you already have a Cursor account, cursor.com opens cursor.com/agents instead of the download page. The address cursor.com/home always shows the download button.

Step 1: Install on macOS

  1. Open the downloaded file. A window shows the Cursor icon, an arrow, and an Applications folder.
  2. Drag the Cursor icon onto the Applications folder. Wait until the copy finishes.
  3. Open Cursor from your Applications folder.
  4. If macOS asks to allow notifications from Cursor, choose either option. It does not change these steps.
No admin rights

Do not run install commands that ask for admin rights or an elevated account. If the installer asks for that, stop and ask a helper.

Step 1: Install on Windows

  1. Open the downloaded file. A window titled "Setup - Cursor (User)" opens. It shows the License Agreement screen.
  2. Select I accept the agreement. Click Next.
  3. Click Next on each of the next three screens: "Select Destination Location", "Select Start Menu Folder", and "Select Additional Tasks". Do not change the settings.
  4. On the "Ready to Install" screen, click Install. Wait until the green bar is full. This takes about 1 minute.
  5. On the "Completing the Cursor Setup Wizard" screen, keep Launch Cursor selected. Click Finish. Cursor opens.

Step 2: Click Sign Up

Cursor opens a window with the Cursor logo, the text "The best way to code with AI", and two buttons: Log In and Sign Up.

  1. Click Sign Up. Your browser opens a page titled "Welcome to Cursor".

If you already have a Cursor account, click Log In instead and sign in with it.

The browser may show a small window "Sign up to Cursor". Click Continue to sign up.

Step 5: Send your first Agent prompt

  1. Click in the prompt box.
  2. Type this text:

  3. Press Enter.

Cursor tour: Open the editor

Session 1 uses the editor window. Open it and find Tab, Ask, and Agent. You do not need to use them yet. You only need to see that each one is there.

  1. In the Cursor Agents window, click IDE at the top right. IDE means integrated development environment, the editor.
  2. A second window opens. Its title is ai-academy-test. The file list on the left shows hello.html.

Cursor tour: Tab

  1. Click hello.html in the file list. The file opens.
  2. Click at the end of the last line and press Enter.
  3. Type <p>Made with and wait 2 seconds. Grey text appears after your text, for example "Cursor</p>". That grey text is the Tab suggestion. Pressing Tab would accept it. Do not press Tab now.
  4. Press Escape. Then press Cmd+Z until your typed text is gone.
  5. Press Cmd+W to close the file.

Cursor tour: Ask and Agent

  1. On the right side of the editor, find the panel named New Agent. It has a prompt box.
  2. Below the prompt box, click the small button with the infinity symbol. A list opens: Agent, Plan, Debug, Multitask, Ask. Agent has a check mark.
  3. Click Agent to close the list.

Shortcut for later: Shift+Cmd+L opens a new Agent in the editor.

If it fails

  1. Do not spend more than 10 minutes on your own.
  2. Pair with a neighbor who has a working install. Watch the demo on their machine.
  3. Tell a helper or the instructor, so they can look at your laptop after class.

Ask the program lead if you have a question about your account before the session.

You are ready

If all four are checked, your install is ready for Session 1.
