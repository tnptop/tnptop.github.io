## 2. Write one idea for your capstone project

At the end of the program, you build a capstone project. It can be a
twist on what Session 2 or Session 4 builds, or a fresh idea from your
own work. Today you saw what an agent can build from a plain
requirement. Use that to imagine one tool you want.

Write the idea as a requirement, in 5 lines. Use this shape:

```
Who uses it: <one line>
What data it holds: <one line>
What actions it needs: <one line>
What "done" looks like: <one line>
One constraint: <one line, for example no internet access, or must run on an existing laptop>
```

Keep this file. You do not need to show it in Session 2. You come back
to it when the capstone starts, and it is fine if the idea changes by
then.
