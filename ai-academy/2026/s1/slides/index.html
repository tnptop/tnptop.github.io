Fundamentals

Recap: LLM (Large Language Model)

From AI foundation

A model trained on a vast amount of text, that predicts the next word. A very good autocomplete

โมเดลภาษาขนาดใหญ่ — โมเดลที่เรียนรู้จากข้อความจำนวนมาก แล้วทำนายคำถัดไป

One more thing for engineers

  • Pure function: text in, next token out
  • No memory between calls. It never runs your code
  • The harness is the program around the model. It resends the context, calls tools, and runs commands. Cursor is a harness. GitHub Copilot is another one

ฮาร์เนส — โปรแกรมที่ครอบโมเดล ส่งบริบท เรียกเครื่องมือ และรันคำสั่งให้

Fundamentals

On the buildingIn agentic AI
The brainThe model: it thinks and decides, then sends signals. It cannot touch anything
The body, plus the harness it wearsThe harness (today: Cursor): it follows the signals, reads and writes files, and runs commands
Gear clipped on with karabinersTools, rules, skills, MCP servers
The safety line to the roofYour approvals. Auto-run off

Fundamentals

Recap: token

From AI foundation

A small piece of text, close to a word or part of a word

Rule of thumb

  • 1 token is about 4 English characters (4 bytes)
  • 1,000 tokens is about 750 English words (4 KB)

โทเคน — หน่วยย่อยของข้อความที่โมเดลใช้อ่านและเขียน

One more thing for engineers

  • Code and Thai cost more tokens per character than English
  • Thai is 3 bytes per character in UTF-8. The 4-byte rule does not work for Thai
  • More tokens: more cost, slower, less room
  • Long chats with big pasted files get slow, expensive, and fill the context window (next)

Fundamentals

Recap: context window

From AI foundation

The amount of text the model can hold at once

Counted in tokens

For example, 256K tokens is about 1 MB of English text (slide 9, "Recap: token")

ขนาดหน้าต่างบริบท — จำนวนโทเคนที่โมเดลอ่านได้ในครั้งเดียว

One more thing for engineers

  • One window holds: system prompt, tool definitions, rules, skills, MCP tools, and the conversation
  • Every message resends the whole chat: your prompts, @‑files, and every tool result (slide 7, "Recap: LLM")
  • When it fills, the harness summarizes or drops older parts
  • So: start a new chat per task, and @-mention only what matters

Fundamentals

Recap: hallucination

From AI foundation

A confident answer that is wrong

อาการมั่ว — โมเดลตอบสิ่งที่ฟังดูมั่นใจแต่ไม่จริง

Readjust

  • The model is not confident. It writes the most likely next token
  • No "I am not sure" signal, and no tone or body language: a smooth answer reads as certain
  • It is trained to write fluent prose, and the chat hides the token probabilities

Fundamentals

Recap: hallucination

From AI foundation

A confident answer that is wrong

อาการมั่ว — โมเดลตอบสิ่งที่ฟังดูมั่นใจแต่ไม่จริง

One more thing for engineers

  • The common shape: gap filling
  • The model has no file, doc, or data value, so it guesses
  • The guess looks like a real API, flag, or path
  • Often the right file was available, but nobody showed it to the model

The fix is not "ask again".

  • Show the model the real file or docs
  • Run the code: the compiler or test tells the truth

Fundamentals

Keyword: non‑deterministic

The keyword

The same prompt can give a different answer each time. This is normal model behavior, not a bug

ผลลัพธ์ไม่คงที่ — ถามคำถามเดิมสองครั้ง อาจได้คำตอบต่างกัน

One more thing for engineers

  • The model samples the next token. It does not pick the single best one
  • Same dice roll as slide 11, "Recap: hallucination": a likely token, not the one right answer
  • Do not expect the same code twice
  • Pin behavior with a spec and a test. Compare plans, not first impressions

Fundamentals

Keyword: tool use

  • The model cannot run anything. It only writes text (slide 7, "Recap: LLM")
  • In: the harness puts the tool list into the context (name, purpose, inputs)
  • Out: the model is trained to write a tool call: the tool name plus its inputs
  • Back in: the harness runs the call and pastes the result into the context
  • The brain sends the signal. The body runs it (slide 8, "Keyword: harness")

การใช้เครื่องมือ — โมเดลเขียนคำขอ แล้วฮาร์เนสเป็นผู้รันให้

Fundamentals

Keyword: agent loop

  • Plan, act, observe, repeat
  • Your own loop: read, write code, run the test, read the result, fix
  • The agent runs the same loop, with tools (slide 14, "Keyword: tool use") in place of your hands

วงจรเอเจนต์ — วางแผน ลงมือทำ ดูผล แล้ววนซ้ำ

Fundamentals

Keyword: agent loop

  • How does it know it is right? It runs the tests and reads the output
  • No test and no error output: nothing to observe, so it guesses (slide 12, "Recap: hallucination")
  • Each turn adds a tool result, so a long run fills the window (slide 10, "Recap: context window")
  • It ends with a final answer, or when you stop it

Fundamentals

The cost of autonomy

  • More autonomy means more steps you did not read
  • AI Foundation, module 3: AI suggests, you decide, and you are responsible
  • Pick the lowest level that does the job
  • Read and verify before you accept: the agent checks its tests, you check the agent

Roadmap and peek

Peek: MCP (Model Context Protocol)

Without MCP, you copy a ticket from the ticket system and paste it into the chat.

With MCP, the agent reads the ticket itself.

  • MCP is the standard that makes this work: a server exposes tools and data, the agent calls them. An MCP server is gear that clips onto the harness
  • Company rule: only MCP servers IT has approved, even for a prototype. Ask your UM for the list
  • Full depth in Session 4

Roadmap and peek

Peek: skills and commands

  • A skill is a saved procedure in a Markdown file (SKILL.md). Example: "review this file: run the linter, list each problem, propose a fix"
  • The agent starts a skill by itself when the task matches. Rules are always on (from the tour)
  • Skills are an open standard. They clip onto the harness
  • A command is a saved prompt. You start one with / in the chat. Most harnesses have skills and commands
  • Full depth in Session 4

Roadmap and peek

Peek: responsible use

  • AI Foundation rules still apply: classify data before you paste, no secrets or personal data, verify before you use. You own the decision
  • New with an agent: it acts, not only answers. Read every command before you approve it. Keep auto-run off
  • CIO-certified at every company: Cursor (all its models), Gemini, GitHub Copilot. Codex and Claude Code are not on the list. Your company IT may allow them. Ask your UM
  • Use your company Cursor account only. No secrets in prompts, rules files, or code
